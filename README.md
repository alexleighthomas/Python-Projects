<h1> Python Fundamentals Project — Data Technician Bootcamp </h1>
<h2> Building Logic, Interactivity, and Problem‑Solving with Core Python Skills </h2>
<p1> This project was completed during the **Data Technician Bootcamp** and demonstrates practical Python programming skills used to build logic, perform calculations, and interact with users. The work focuses on foundational concepts essential for real‑world scripting, automation, and data handling. </p1>

<h2> 🧰 Core Python Skills Demonstrated </h2>
<h3> 🔹 Variables </h3>
<p1> Used to store and manipulate values such as numbers, strings, and user inputs.  
Examples included tracking totals, storing user responses, and holding intermediate calculation results. </p1>

<h3> 🔹 'print()' Function </h3>
<p1> Used throughout the project to display messages, results, and instructions to the user, forming the basis of user interaction. </p1>

<h3> 🔹 'input()' Function </h3>
<p1> Enabled dynamic programs where users could enter values such as names, numbers, or menu choices.  
This allowed scripts to behave differently depending on user input. </p1>

<h3> 🔹 Type Casting </h3>
<p1> Converted input values (which are strings by default) into integers or floats using functions like `int()` and `float()`.  
This made it possible to perform mathematical operations and comparisons. </p1>

<h2> 🧠 Building Logic with Conditionals </h2>
<h3> 🔹 If Statements </h3>
<p1> 
Used to make decisions based on user input or calculated values.  
Examples included:

- Checking whether a number is positive or negative  
- Validating user choices  
- Applying different calculations depending on conditions  

These conditional structures formed the backbone of program logic.
</p1>

<h2> 🔁 Loops for Repetition and Automation </h2>
<h3> 🔹 For Loops </h3>
<p1> 
Used to iterate through sequences such as lists or ranges.  
Examples included:

- Repeating actions a set number of times  
- Processing items in a collection  
- Generating repeated output
</p1>

<h3> 🔹 While Loops </h3>
<p1>  
Used to create programs that run until a condition changes.  
Examples included:

- Input validation loops  
- Menu systems that continue until the user exits  
- Repeated calculations based on user choice  

Loops allowed the project to automate repetitive tasks and build interactive workflows.
</p1>

<h2> 🧮 Practical Applications </h2>
<p1> 
Across the project, these Python fundamentals were combined to create small but functional programs, such as:

- Simple calculators  
- Interactive questionnaires  
- Number‑checking or classification scripts  
- Menu‑driven tools  
- Repetitive processing tasks  

Each exercise reinforced how variables, logic, and loops work together to form complete programs.
</p1>

<h2> 📚 Technologies & Concepts Used </h2>
<p1> 
  
- Python 3  
  
- Variables and data types
  
- `print()` and `input()`
  
- Type casting (`int()`, `float()`, `str()`)
  
- Conditional logic (`if`, `elif`, `else`)
  
- `for` and `while` loops
  
- Basic arithmetic and comparisons  
</p1>
